# Paket Controlled Rebuild Tugas Akhir

**Fokus:** Integrasi dan Rekonsiliasi Data Portofolio Aset Finansial Berbasis Web.

Paket ini adalah **spesifikasi kerja awal**, bukan bukti bahwa kode, PDF, atau proposal terkini telah diaudit. AI Agent harus memeriksa repository dan dokumen aktual sebelum implementasi.

## Cara pakai
1. Backup repository lokal dan pastikan branch Git aman.
2. Ekstrak paket ke root repository, tanpa menimpa file lama sebelum dibandingkan.
3. Baca `AGENT_START_PROMPT.md` dan berikan seluruh isinya ke Agent.
4. **Tahap pertama hanya audit dan rencana**. Jangan langsung coding atau menghapus kode.
5. Tinjau laporan audit, lalu setujui migrasi/implementasi per increment.

## Dokumen
- `PROJECT_CONTEXT.md`: tujuan, ruang lingkup, keputusan
- `ARCHITECTURE.md`: alur, modul, boundary
- `DATA_CONTRACTS.md`: entitas, transaksi, snapshot, provenance
- `RECONCILIATION_SPEC.md`: aturan mesin rekonsiliasi
- `SOURCE_MATRIX.md`: sumber dokumen terkonfirmasi dan belum pasti
- `IMPLEMENTATION_ROADMAP.md`: urutan increment dan gates
- `TEST_PLAN.md`: skenario, metrik, evidence
- `SECURITY_AND_GIT.md`: keamanan dokumen dan Git
- `AGENT_RULES.md`: protokol kerja Agent
- `DECISION_LOG.md`: keputusan dan pertanyaan terbuka
- `AGENT_START_PROMPT.md`: prompt untuk Agent

**Catatan:** Judul akademis resmi jangan diganti tanpa persetujuan dosen pembimbing.
