# UI DESIGN REFERENCE

`dashboard-ui-reference.png` is the visual reference for the desired application UI.

Use it as a visual/design reference, not as a source of exact data.

Target characteristics:
- desktop dashboard layout;
- dark navy/blue sidebar;
- light background/content area;
- blue primary accents;
- white rounded cards;
- clean financial dashboard appearance;
- portfolio value, investment, profit/loss, dividend cards;
- portfolio performance chart;
- asset allocation chart;
- largest assets table/list;
- recent transactions;
- acquisition mode panel;
- responsive behavior.

IMPORTANT:
- Do not copy fictional numbers from the image as real application data.
- Preserve the project's functional architecture and Incremental Development scope.
- UI styling can evolve, but the overall visual language should remain close to this reference unless the user explicitly requests a change.
